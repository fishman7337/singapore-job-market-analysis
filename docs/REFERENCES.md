# References

The original notebook contains the detailed citation list used for the academic submission. Keep source references close to the analysis cells that use them so markers can connect claims to evidence.

When adding new sources:

- Prefer primary data publishers and official statistics portals.
- Record publication dates and access dates where available.
- Avoid mixing incompatible survey definitions without explaining the limitation.
- Note whether values are nominal, real, seasonally adjusted, or otherwise transformed.
