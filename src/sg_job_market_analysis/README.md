# `sg_job_market_analysis`

Reusable Python package for the CA2 Singapore graduate employment and labour market analysis.

| Module | Purpose |
| --- | --- |
| `cleaning.py` | Data cleaning helpers |
| `contracts.py` | Dataset contract definitions |
| `dataops.py` | Data quality command-line entrypoint |
| `features.py` | Feature engineering helpers |
| `paths.py` | Shared project paths |
| `validation.py` | Validation primitives |

Keep notebook-specific experimentation out of this package unless the logic is reusable and tested.
